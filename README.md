# Duplicate Photo Cleaner

[![Build and Release](https://github.com/YOUR_USERNAME/duplicate-photo-cleaner/actions/workflows/build-and-release.yml/badge.svg)](https://github.com/YOUR_USERNAME/duplicate-photo-cleaner/actions/workflows/build-and-release.yml)

A cross-platform desktop application for finding and safely removing duplicate photos with an intuitive user interface.

## 🚀 Features

- **🔍 Smart Detection**: Uses perceptual hashing to find visually similar images
- **🛡️ Safety First**: Moves duplicates to a holding folder before permanent deletion
- **👥 Multi-User Support**: Secure user authentication with individual settings
- **📊 Action History**: Complete audit trail of all operations
- **🖼️ Visual Comparison**: Side-by-side preview of duplicate pairs
- **⚙️ Configurable**: Customize retention periods and storage locations
- **🖥️ Cross-Platform**: Works on Windows, macOS, and Linux

## 🔧 Installation

### Pre-built Binaries

1. Download the appropriate zip file for your operating system
2. Extract the contents to a folder of your choice
3. Run the executable:
   - **Windows**: `DuplicatePhotoCleaner.exe`
   - **macOS/Linux**: `./DuplicatePhotoCleaner`

### From Source

**Requirements**: Python 3.8 or higher

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/duplicate-photo-cleaner.git
cd duplicate-photo-cleaner

# Install dependencies
pip install -r requirements.txt

# Run the application
python main.py
